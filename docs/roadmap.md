# Product Roadmap

## Phase 1 (CURRENT - 40%)
**Video Monitoring, PPE Detection, Obstacle Detection**
- Core backend/frontend setup
- YOLOv8 ML integration
- Basic alerting
- Docker containerization

## Phase 2 (60-70%)
**Advanced PPE, Fall Detection, Pose Estimation, Unsafe Behavior, Restricted Areas**
- Integrating pose estimation models
- Temporal logic for fall detection
- Fine-grained zoning rules

## Phase 3 (70-80%)
**IoT Integration, Gas/Smoke/Temp Monitoring**
- Webhooks for sensor hardware
- Integrated dashboards

## Phase 4 (80-90%)
**Advanced Analytics, Reports, Predictive Safety**
- Automated PDF report generation
- Heatmaps for safety bottlenecks
- Predictive trend models

## Phase 5 (90-100%)
**Privacy, Auth, Multi-site, Production Optimization**
- RBAC, JWT Auth
- Edge device synchronization
- TensorRT optimizations
